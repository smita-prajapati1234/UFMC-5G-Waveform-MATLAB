# UFMC 5G Waveform – MATLAB

## Universal Filtered Multi-Carrier (UFMC) for 5G Wireless Communication

This repository presents MATLAB-based implementation, simulation, and performance analysis of Universal Filtered Multi-Carrier (UFMC) waveform for 5G wireless communication systems.

UFMC is a multicarrier waveform technique based on subband filtering and is investigated for improved spectral containment, reduced out-of-band emissions, and flexible waveform design for advanced wireless communication systems.

## Project Objectives

- Implementation of UFMC transmitter and receiver using MATLAB
- UFMC waveform generation and analysis
- Wireless channel analysis
- Different QAM modulation schemes
- Filter type and filter parameter analysis
- FFT length and subband analysis
- Stopband attenuation analysis
- Power Spectral Density (PSD) analysis
- Peak-to-Average Power Ratio (PAPR) analysis
- UFMC versus OFDM comparison
- UFMC-based NOMA analysis
- BER and SNR performance evaluation

## Simulation Studies

The repository contains MATLAB studies covering:

1. Basic UFMC waveform
2. UFMC channel analysis
3. Different QAM modulation schemes
4. UFMC filter analysis
5. FFT length analysis
6. Subband analysis
7. Filter length and stopband attenuation
8. PAPR and PAPR versus filter length
9. PSD and waveform analysis
